# MATLAB 课堂补充脚本（M00–M02）

导引：[guides/matlab/README.md](../../guides/matlab/README.md)

## 快速开始（Windows 机房）

1. MATLAB **当前文件夹** = 仓库根目录。
2. 命令窗口：

```matlab
run('code/matlab/setup_repo_path.m')
m00_basics
m01_verify_rtb      % 需已安装 RTB.mltbx
m01_plot_frames
m02_run_checks
```

## 文件

| 脚本 | 说明 |
|------|------|
| `setup_repo_path.m` | 把本目录加入路径 |
| `m00_basics.m` | 向量、矩阵、绘图 |
| `m01_verify_rtb.m` | 检查 SE3 / trplot |
| `m01_plot_frames.m` | 坐标系可视化 |
| `m02_run_checks.m` | 当堂自检（含练习 1 数值） |

## B.1 从函数版 PID 迁移到类

### 函数版（状态散落）

```python
integral = 0.0
prev_e = 0.0

def pid_step(e, dt, Kp, Ki, Kd):
    global integral, prev_e
    integral += e * dt
    d = (e - prev_e) / dt
    prev_e = e
    return Kp * e + Ki * integral + Kd * d
```

问题：`global` 难维护，多个控制器时更易乱。

### 类版（推荐）

见 T01 §1.14.3；本节约 **加练**。

**练习 ⭐**：把函数版改成类，且 **禁止** `global`。

## B.2 一阶对象：真正接入控制量 `u`

修改 T01 中的 `FirstOrderSystem`，使输入影响导数（一阶惯性 + 输入增益）：

\[
\dot{y} = \frac{K_{ref} - y}{\tau} + k_u \cdot u
\]

简化取 \(K_{ref}=1\) 为设定稳态，\(k_u=0.5\)：

```python
class FirstOrderPlant:
    def __init__(self, tau: float, y0: float = 0.0, ku: float = 0.5) -> None:
        self.tau = tau
        self.y = y0
        self.ku = ku
        self.setpoint = 1.0

    def step(self, dt: float, u: float) -> float:
        dy = (self.setpoint - self.y) / self.tau + self.ku * u
        self.y += dt * dy
        return self.y


plant = FirstOrderPlant(tau=0.8, y0=0.0)
print(plant.step(0.05, u=0.0))
print(plant.step(0.05, u=1.0))
```

**练习 ⭐**：固定 `u=0` 跑 20 步，`y` 是否趋近 `setpoint`？（会：开环项 \((1-y)/\tau\) 已把平衡点设在 1。）  
**练习 ⭐**：把 `ku` 改为 `0` 再跑 B.4 闭环：`u` **进不了** 对象，PID 无效，曲线与开环几乎一样。要看闭环，须 `ku>0`。

## B.3 完整 PID 类（带 `reset` 与限幅）

```python
class PID:
    def __init__(self, Kp, Ki, Kd, u_min=-5.0, u_max=5.0):
        self.Kp, self.Ki, self.Kd = Kp, Ki, Kd
        self.u_min, self.u_max = u_min, u_max
        self.integral = 0.0
        self.prev_error = 0.0

    def reset(self):
        self.integral = 0.0
        self.prev_error = 0.0

    def step(self, error: float, dt: float) -> float:
        self.integral += error * dt
        deriv = (error - self.prev_error) / dt if dt > 0 else 0.0
        u = self.Kp * error + self.Ki * self.integral + self.Kd * deriv
        u = max(self.u_min, min(self.u_max, u))
        self.prev_error = error
        return u
```

**常见错误 vs 推荐**

```python
# ❌ 仿真 for 循环内：pid = PID(...)  # 每步清空积分
# ✅ 循环外创建一次 pid

# ❌ 改 Kp 后不 reset，积分仍带着旧轨迹
# ✅ 调参对比前 pid.reset()
```

## B.4 闭环仿真 50 步（本讲核心交付）

```python
def run_closed_loop(steps: int = 50, dt: float = 0.05) -> None:
    plant = FirstOrderPlant(tau=0.8, y0=0.0, ku=0.4)
    pid = PID(Kp=1.2, Ki=0.3, Kd=0.05)
    r = 1.0
    for k in range(steps):
        e = r - plant.y
        u = pid.step(e, dt)
        y = plant.step(dt, u)
        if k % 10 == 0:
            print(f"k={k:2d}  y={y:.4f}  e={e:.4f}  u={u:.4f}")


if __name__ == "__main__":
    run_closed_loop()
```

**练习 ⭐**：运行后，最后 `y` 是否接近 `r=1`？  
**练习 ⭐**：`Ki=0` 只保留 P，观察是否达不到 1（稳态误差）。  
**练习 🔶**：把 `Kd` 调到 `0.5`，看是否更「抖」（对噪声敏感预习）。

## B.5 用类打包「仿真配置」

class SimulationConfig:
    def __init__(self, dt: float, steps: int, setpoint: float) -> None:
        self.dt = dt
        self.steps = steps

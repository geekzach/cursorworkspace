# 总教程 · Python + 控制 + AI 入门（两轮自平衡小车项目）

本目录是**完整、可独立阅读**的中文教程序列，不依赖「按周拆开的碎片」。  
每周打卡只告诉你**本周建议读哪几节、做哪几个脚本**——见 [`docs/checklists/`](../checklists/)。

---

## 读者与前提

- **读者**：西电机器人方向大三同学，Python 较弱，使用 **VS Code + WSL**，可用 **conda** 管理环境（本仓库示例以 `venv` + `pip` 为主，conda 等价操作见 [T00 §0.3](T00-导读与环境.md#03-开发环境vscode--wsl--python)）。
- **目标**：为 **东南大学 085400 专硕复试** 准备「倒立摆 → 平衡车」主线，并可选走 **AI01（神经网络拟合动力学）** 分支，日后衔接 MuJoCo 与强化学习。

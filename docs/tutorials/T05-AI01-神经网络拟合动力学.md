## 5.2 监督学习最小集（先建立再调网络）

| 概念 | 本实验 |
|------|--------|
| 样本 | \((\theta,\omega,u)\) → RK4 一步后的 \((\theta^+,\omega^+)\) |
| 训练/验证 | 如 80% / 20%；**验证集不参与梯度** |
| 损失 MSE | 预测与真值均方误差 |
| 过拟合 | 训练 MSE 很低、验证 MSE 高 |
| 容量 | `hidden_dim` 越大越容易过拟合 |

### 5.2.1 跑通：玩具线性回归（1 维，无网络）

```python
import numpy as np
rng = np.random.default_rng(0)
x = rng.uniform(-1, 1, 100)
y_true = 2.0 * x + 0.5
# 故意加噪声
y = y_true + rng.normal(0, 0.05, 100)
# 最小二乘闭式解（理解「拟合」即可）
A = np.vstack([x, np.ones_like(x)]).T
coeff, _, _, _ = np.linalg.lstsq(A, y, rcond=None)
print("拟合斜率≈2", coeff)
```

**练习 ⭐**：把噪声加大到 0.5，斜率估计会怎样抖？

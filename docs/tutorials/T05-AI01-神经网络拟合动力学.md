## 5.1 为什么要「学习」动力学

经典路线：白盒 \(\dot{x}=f(x,u)\) 来自力学。  
**数据驱动**：用真 ODE **rollout** 生成 \((\theta,\omega,u)\to(\theta^+,\omega^+)\)，让小型 **MLP** 学一步预测。

- 与 PID/LQR 共用同一类信息：系统怎么动  
- 为 T06 强化学习打底（函数逼近），不是替代经典主线

实现：**仅 numpy + matplotlib**；核心库在 `src/ai01/`。

## 5.2 监督学习最小集（必须先建立，再调网络）

在写 MLP 之前，请明确这是 **系统辨识（system ID）** 里的监督学习，不是强化学习：

| 概念 | 在本实验中的含义 |
|------|------------------|
| **样本** | 一条 \((\theta,\omega,u)\) 与真 ODE 积分得到的 \((\theta^+,\omega^+)\) |
| **训练集 / 验证集** | 例如 80% / 20%；**验证集不参与梯度更新** |
| **损失 MSE** | 预测与真值的均方误差；越小越好，但… |
| **过拟合** | 训练 MSE 很低、验证 MSE 很高 → 网络过大或样本太少 |
| **容量** | `hidden_dim` 越大，越容易拟合训练集，也更容易过拟合 |

外部对照：Virk [ML Bible](https://www.arjunvirk.com/writing/ml-guide) 中 **Classical ML** 与 **Neural Networks** 章节的「损失、泛化」讨论；本仓库用 NumPy 手写，与「先理解再上框架」一致。

**错误路线（请勿）**：未划分验证集、只看训练 loss 下降、或跳过 T03 直接抄 `demo_reference_end2end.py` 交作业。

## 5.3 本仓库监督信号

简化摆（见 [T03 §3.6](T03-常微分方程与仿真直觉.md#pendulum-rk4)）：

- 输入：\(\theta,\omega,u\)  
- 标签：RK4 积分 **一步** 后的 \(\theta^+,\omega^+\)  
- 损失：**MSE**；报告时 **同时给出训练集与验证集 MSE**

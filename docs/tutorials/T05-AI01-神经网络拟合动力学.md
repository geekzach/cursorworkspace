## 5.1 为什么要「学习」动力学

经典路线：白盒模型 \(f(x,u)\) 来自力学推导。  
**数据驱动**路线：在仿真或实验轨迹上拟合 \(\dot{x} \approx f_\theta(x,u)\)，用于：

- 模型不准时的补偿  
- 快速原型（先拟合再控制）  
- 与 **强化学习** 衔接（T06）

本仓库 **AI01** 用纯 NumPy 实现小 MLP，**不新增** PyTorch 等依赖，与 `requirements.txt` 一致。

---

## 5.2 监督学习设定

收集数据集 \(\{(x^{(i)}, u^{(i)}, \dot{x}^{(i)})\}_{i=1}^N\)：

- 真值 \(\dot{x}^{(i)}\) 来自解析模型或 `solve_ivp` 数值差分  
- 网络输入：拼接 \([x, u]\)  
- 网络输出：预测 \(\dot{x}\)  
- 损失：均方误差 \(\mathrm{MSE} = \frac{1}{N}\sum \|\dot{x}_\theta - \dot{x}\|^2\)

这是 **动力学辨识**，不是端到端 RL；但能训练你处理张量形状、梯度下降与过拟合。

---

## 5.3 两层 MLP 与反向传播（NumPy）

结构：\(\mathbb{R}^{n_{in}} \to \mathbb{R}^{h} \to \mathbb{R}^{n_{out}}\)，激活 ReLU / tanh。

实现要点（见 `weeks/ai01_dynamics_fit/train_mlp_numpy.py`）：

1. 前向：`z1 = x @ W1 + b1`, `h = relu(z1)`, `y = h @ W2 + b2`  
2. 反向：链式法则更新 `W1, b1, W2, b2`  
3. 学习率 \(\eta\) 过大振荡，过小收敛慢

---

## 5.4 实验流程（AI01 标准作业）

1. **生成数据**：一维或二维线性系统，加少量噪声  
2. **划分**训练 / 测试（如 80/20）  
3. **训练** 500–2000 epoch，记录 loss 曲线  
4. **评估**：测试集 MSE；画「真 \(\dot{x}\) vs 预测」  
5. **对照**：与真实 \(A,B\) 线性模型比，能解释何时 NN 更划算

---

## 5.5 与经典控制、复试叙事

- **可解释性**：LQR 用 \(A,B\) 直接讲极点；NN 用数据讲拟合误差。  
- **安全**：实物上勿盲目用未验证的 NN 力矩；先仿真闭环。  
- **延伸**：T06 把「拟合好的环境」换成 RL 环境接口。

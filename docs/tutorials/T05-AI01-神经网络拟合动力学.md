## 5.2 监督学习词典（先背再用）

| 术语 | AI01 含义 |
|------|-----------|
| 特征 \(x\) | \([\theta,\omega,u]\) 或拼接向量 |
| 标签 \(y\) | RK4 一步后的 \([\theta^+,\omega^+]\) |
| 训练集 | 用于更新权重 |
| 验证集 | **不参与**梯度，用来估泛化 |
| 损失 MSE | \(\frac1N\sum\|\hat{x}^+-x^+\|^2\) |
| 过拟合 | 训练 MSE 很低、验证 MSE 高 |
| 容量 | `hidden_dim` 越大，越能记训练集 |

对照 [ML Bible](https://www.arjunvirk.com/writing/ml-guide) 的 classical / NN 章：**理解损失与泛化**，不必做 Vision/Agent 章。

## 5.3 玩具实验 1：线性回归（无网络）

```python
import numpy as np
rng = np.random.default_rng(0)
N = 200
x = rng.uniform(-1, 1, N)
y_true = 2.0 * x + 0.5
y = y_true + rng.normal(0, 0.05, size=N)

A = np.vstack([x, np.ones(N)]).T
coeff, _, _, _ = np.linalg.lstsq(A, y, rcond=None)
print("斜率、截距≈", coeff)

# 手动 MSE
y_hat = coeff[0] * x + coeff[1]
mse = np.mean((y_hat - y) ** 2)
print("MSE", mse)
```

**练习 ⭐**：噪声 `0.05→0.5`，MSE 与系数抖动如何变？

## 5.5 简化摆：连续模型复习

\[
\dot\theta = \omega,\quad
\dot\omega = -\frac{g}{L}\sin\theta - b\omega + \frac{u}{mL^2}
\]

```python
import numpy as np

def deriv(theta, omega, u, m=0.2, L=0.5, g=9.81, b=0.02):
    return omega, -(g/L)*np.sin(theta) - b*omega + u/(m*L**2)
```

## 5.6 一步预测作为监督样本

给定 \((\theta_k,\omega_k,u_k)\)，用 RK4 得 \((\theta_{k+1},\omega_{k+1})\)。

```python
# 概念代码 — 实际见 rollout.py
from ai01.pendulum import PendulumParams, rk4_step
import numpy as np

p = PendulumParams()
state = np.array([0.1, 0.0])
u = 0.5
dt = 0.01
next_state = rk4_step(state, u, dt, p)
print("x+", next_state)
```

网络学的是：

\[
[\hat{\theta}^+,\hat{\omega}^+] \approx f_\theta([\theta,\omega,u])
\]

或学 **增量** \(\Delta x\)（实现细节见 `ex02`）。

**练习 ⭐**：同一 `state,u`，把 `dt` 加倍，\(\theta^+\) 变化更大还是更小？跑一下验证。

## 5.7 网络结构（两层 MLP 够用）

```text
输入 (3) → 隐藏 (hidden_dim) → ReLU → 输出 (2)
```

`src/ai01/mlp_numpy.py` 已实现 `forward` / `backward`。

### 5.7.1 前向传播（读代码时对照）

```python
# 极简 1 隐藏层示意（非仓库完整实现）
import numpy as np

def relu(z):
    return np.maximum(0, z)

def mlp_forward(x, W1, b1, W2, b2):
    h = relu(x @ W1 + b1)
    y = h @ W2 + b2
    return y, h
```

**不要**本周手写完整 BP 作为必做；**要**能说出「链式法则让梯度往回传」。

## 5.11 超参与调试清单

| 现象 | 可能原因 | 尝试 |
|------|----------|------|
| train、val 都高 | lr 太大/太小、训练不够 | 调 lr、加 epoch |

## 5.18 精读 `rollout.py`（逐行对照）

```python
# 核心循环逻辑（与仓库一致）
for i in range(n_samples):
    theta = rng.uniform(-0.8, 0.8)
    omega = rng.uniform(-2.0, 2.0)
    u = rng.uniform(-0.5, 0.5)
    state = np.array([theta, omega])
    next_state = rk4_step(state, u, dt, params)
    X[i, :] = (theta, omega, u)
    Y[i, :] = next_state
```

| 设计 | 原因 |
|------|------|
| \(\theta\in[-0.8,0.8]\) | 覆盖小角度与大角，学 \(\sin\theta\) |

## 5.20 Mini-batch 为何有用

全批量梯度：每次用全部训练点，内存大、更新慢。  
Mini-batch：每次用 `batch_size` 条，噪声大但 **更快迭代**。

```python
# 概念：打乱索引，按块切
n = X_train.shape[0]
batch_size = 64
perm = rng.permutation(n)
for start in range(0, n, batch_size):
    batch_idx = perm[start : start + batch_size]
    # 用 X_train[batch_idx] 算梯度
```

**练习 🔶**：`batch_size=n` 与 `batch_size=32` 训练曲线是否更抖？

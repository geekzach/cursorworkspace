## 3.1 状态、输入与 ODE（连续时间语言）

### 3.1.1 一句话定义

**常微分方程（ODE）**描述状态**瞬时变化率**如何依赖当前状态与输入：

\[
\dot{x}(t) = f(x(t), u(t))
\]

| 符号 | 含义 | cart-pole 例子 |
|------|------|----------------|
| \(x\) | 状态向量 | cart-pole 常写 \([p,\ \dot{p},\ \theta,\ \dot{\theta}]^\top\)（\(p\) 为小车位置，避免与状态符号 \(x\) 撞名） |
| \(u\) | 控制输入 | 作用在小车上的水平力 \(F\) |
| \(f\) | 右端（动力学） | 由牛顿/拉格朗日得到 |
| \(\dot{x}\) | 对时间的导数 | 代码里返回的 `dxdt` |

**仿真**不是求「公式解」，而是：给定 \(x(t_0)\) 和 \(u(\cdot)\)，在离散时刻 \(t_k\) **数值逼近** \(x(t_k)\)。

### 3.1.2 跑通：标量指数衰减 + 解析对照

物理意义：RC 电路、温升、一阶惯性环节都可写成 \(\dot{y}=-y/\tau\)（与 T02 阶跃响应同一族）。

\[
\dot{y} = -\frac{y}{\tau},\quad y(0)=1 \quad\Rightarrow\quad y(t)=e^{-t/\tau}
\]

```python
import numpy as np

tau = 0.5
for t_check in (0.0, 0.5, 1.0, 2.0):
    print(f"t={t_check:.1f}  y={np.exp(-t_check / tau):.4f}")
```

**练习 ⭐**：`tau` 从 `0.5` 改为 `2.0`，在 `t=1` 时 \(y\) 变大还是变小？用一句话解释（时间常数越大，衰减越慢）。

### 3.1.3 单位与符号（避免仿真翻车）

| 量 | 常用单位 | 笔记 |
|----|----------|------|
| 时间 \(t\) | s | `dt` 与 `dt` 同单位 |
| 角度 \(\theta\) | rad | **不要用度**进 `sin/cos` |
| 角速度 \(\omega\) | rad/s | IMU 常直接给 |
| 力矩 \(u\) | N·m | 与 `pendulum.py` 一致 |

```python
import numpy as np
theta_deg = 5.0
theta_rad = np.deg2rad(theta_deg)
print(np.sin(theta_rad), np.sin(theta_deg))  # 第二个是错的用法
```

**常见错误 vs 推荐**

```python
# ❌ theta = 5  直接代入 sin，当成 5 rad 还好，当成 5° 就错
# ✅ theta_rad = np.deg2rad(5.0)
```

## 3.2 显式欧拉法（必须手写一次）

### 3.2.1 公式

\[
x_{k+1} = x_k + \Delta t \cdot f(x_k, u_k)
\]

对 \(\dot{y}=-y/\tau\)：

```python
import numpy as np

tau = 0.5
dt = 0.05
y = 1.0
t = 0.0
steps = []
for k in range(40):  # 总时长 2 s
    y = y + dt * (-y / tau)
    t += dt
    steps.append((t, y))
print("末值", steps[-1], "解析", np.exp(-2.0 / tau))
```

### 3.2.2 误差从哪来（直觉）

- **截断误差**：直线近似曲线，一步就有误差。  
- **累积误差**：成千上万步叠加。  
- **不稳定**：若 \(\Delta t\) 太大，**数值解会发散**，即使真系统稳定。

经验（初学够用）：\(\Delta t\) 取系统时间常数 \(\tau\) 的 **1/20～1/100**，或取最快振荡周期的一小部分。

### 3.2.3 实验：误差表（必做）

```python
import numpy as np

def euler_decay(tau, dt, t_end, y0=1.0):
    y, t, n = y0, 0.0, 0
    while t < t_end - 1e-12:
        y += dt * (-y / tau)
        t += dt
        n += 1
    return y, n

tau, t_end = 0.5, 1.0
exact = np.exp(-t_end / tau)
print("dt      | y_num    | abs_err")
for dt in (0.2, 0.1, 0.05, 0.01, 0.001):
    y, n = euler_decay(tau, dt, t_end)
    print(f"{dt:6.3f}  | {y:.6f} | {abs(y-exact):.6f}")
```

**练习 ⭐**：完成上表；哪一列 `dt` 对「作业展示」够用？  
**练习 🔶**：把同一 `dt` 画成 `log(dt)` vs `log(err)` 折线（预习数值分析）。

### 3.2.4 常见错误 vs 推荐

```python
# ❌ 隐式欧拉与显式欧拉混写（初学只做显式）
# y = y + dt * (-y_new / tau)

# ❌ dt 与 tau 同量级只积 5 步就抱怨「和公式差太多」
# ✅ 先增加步数或减小 dt

# ❌ 循环里用 float 累加 t 永远不恰好等于 t_end —— 用 while t < t_end 或 for 固定步数
```

## 3.3 二阶系统 → 一阶状态方程（标准套路）

### 3.3.1 质量–弹簧–阻尼

\[
m \ddot{q} + b \dot{q} + k q = u
\]

令 \(x = [q,\ \dot{q}]^\top\)：

\[
\dot{x} = \begin{bmatrix} \dot{q} \\ (u - b\dot{q} - kq)/m \end{bmatrix}
\]

```python
def mass_spring_rhs(t, x, m=1.0, b=0.2, k=4.0, u=0.0):
    q, qd = x[0], x[1]
    qdd = (u - b * qd - k * q) / m
    return [qd, qdd]
```

**纸笔练习 ⭐**：`b=0, u=0` 时 \(\ddot{q} = -(k/m) q\)，这是简谐振动；`qdd` 的符号与 \(q\) 相反说明什么？

### 3.3.2 写成矩阵形式（预习 T04）

\[
\dot{x} = A x + B u,\quad
A = \begin{bmatrix} 0 & 1 \\ -k/m & -b/m \end{bmatrix},\quad
B = \begin{bmatrix} 0 \\ 1/m \end{bmatrix}
\]

```python
import numpy as np
m, b, k = 1.0, 0.2, 4.0
A = np.array([[0, 1], [-k/m, -b/m]])
B = np.array([[0], [1/m]])
x = np.array([0.1, 0.0])
u = 0.0
xdot = A @ x + B.flatten() * u
print("xdot", xdot)
print("与 rhs 一致", mass_spring_rhs(0, x, m, b, k, u))
```

### 3.3.3 倒立摆状态（只建立维数直觉）

cart-pole 常取 \(x=[p,\ \dot{p},\ \theta,\ \dot{\theta}]^\top\)，**4 维**（\(p\) 为小车水平位置）。  
本章用 **2 维** 质量–弹簧练手；`src/ai01/pendulum.py` 用 **2 维** \([\theta,\omega]\) 简化摆。

**练习 ⭐**：口头数出：有几个一阶方程就有几个状态分量。

```python
from scipy.integrate import solve_ivp
import numpy as np
import matplotlib.pyplot as plt

m, b, k = 1.0, 0.2, 4.0

def f(t, x):
    q, qd = x
    u = 0.0
    qdd = (u - b * qd - k * q) / m
    return [qd, qdd]

x0 = [0.15, 0.0]
sol = solve_ivp(f, (0.0, 8.0), x0, max_step=0.02, dense_output=True)

ax[0].plot(t, q); ax[0].set_ylabel("q (m)"); ax[0].grid(True, alpha=0.3)
ax[1].plot(t, qd); ax[1].set_ylabel("qd (m/s)"); ax[1].set_xlabel("t (s)"); ax[1].grid(True, alpha=0.3)
plt.tight_layout()
plt.savefig("weeks/week01/msd_open_loop.png", dpi=120)
print("saved weeks/week01/msd_open_loop.png, q_max=", float(np.max(np.abs(q))))
```

## 3.5 固定步长仿真循环（嵌入式思维）

MCU 上常见结构：

```text
每个周期 dt:
    读传感器 → 算 u = controller(...) → 用 u 更新状态（积分）
```

Python 原型：

```python
import numpy as np

def f_vec(x, u, m=1.0, b=0.2, k=4.0):
    q, qd = x
    qdd = (u - b * qd - k * q) / m
    return np.array([qd, qdd])

dt = 0.001
T = 5.0
n_steps = int(T / dt)
x = np.array([0.1, 0.0])
u = 0.0
hist_t = []
hist_q = []
t = 0.0
for k in range(n_steps):
    hist_t.append(t)
    hist_q.append(x[0])
    x = x + dt * f_vec(x, u)
    t += dt
print("Euler fixed dt final q", x[0])
```

T04 会把 `u` 换成 `pid.step(e, dt)`。


## 3.6 RK4 四阶龙格–库塔

### 3.6.1 算法（读仓库即可实现）

```text
k1 = f(x)
k2 = f(x + dt/2 * k1)
k3 = f(x + dt/2 * k2)
k4 = f(x + dt * k3)
x_next = x + dt/6 * (k1 + 2*k2 + 2*k3 + k4)
```

### 3.6.2 迷你实现（标量，理解用）

```python
def f_scalar(y):
    tau = 0.5
    return -y / tau

def rk4_scalar(y, dt):
    k1 = f_scalar(y)
    k2 = f_scalar(y + 0.5 * dt * k1)
    k3 = f_scalar(y + 0.5 * dt * k2)
    k4 = f_scalar(y + dt * k3)
    return y + (dt / 6.0) * (k1 + 2*k2 + 2*k3 + k4)

y, dt, tau = 1.0, 0.2, 0.5
for _ in range(10):
    y = rk4_scalar(y, dt)
print("rk4 y", y, "exact", __import__("numpy").exp(-2.0/tau))
```

### 3.6.3 简化摆（仓库公式）

\[
\dot\theta = \omega,\quad
\dot\omega = -\frac{g}{L}\sin\theta - b\omega + \frac{u}{mL^2}
\]

```python
# 摘自 src/ai01/pendulum.py 逻辑
import numpy as np

def pendulum_deriv(theta, omega, u, m=0.2, L=0.5, g=9.81, b=0.02):
    theta_dot = omega
    omega_dot = -(g / L) * np.sin(theta) - b * omega + u / (m * L**2)
    return theta_dot, omega_dot
```

非线性在 **\(\sin\theta\)**；小角度 \(\sin\theta\approx\theta\) 才便于线性化（T04）。

## 3.8 事件：积分到「摆倒了就停」

```python
from scipy.integrate import solve_ivp
import numpy as np

def f(t, x):
    theta, omega = x
    g, L, b = 9.81, 0.5, 0.02
    u = 0.0
    return [omega, -(g/L)*np.sin(theta) - b*omega + u]

def fell(t, x):
    theta = x[0]
    return 0.5 - abs(theta)  # 归零时 |theta| 达到 0.5

fell.terminal = True
fell.direction = -1

sol = solve_ivp(f, (0, 10), [0.3, 0.0], events=fell, max_step=0.01)
print("stopped at t", sol.t[-1], "theta", sol.y[0, -1])
```

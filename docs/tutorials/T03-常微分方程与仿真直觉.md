## 3.1 状态、输入与 ODE（连续时间语言）

连续时间系统：

\[
\dot{x}(t) = f(x(t), u(t))
\]

| 符号 | 含义 | cart-pole 例子 |
|------|------|----------------|
| \(x\) | 状态向量 | \(x, \dot{x}, \theta, \dot{\theta}\) |
| \(u\) | 控制输入 | 小车水平力 / 力矩 |
| \(f\) | 动力学 | 拉格朗日推导结果 |

**仿真任务**：给定 \(x(t_0)\) 与输入序列 \(u(t)\)，求离散时刻 \(x(t_k)\)。

### 3.1.1 跑通：标量指数衰减（解析解对照）

\(\dot{y}=-y/\tau,\ y(0)=1\) 的解为 \(y(t)=e^{-t/\tau}\)。

```python
import numpy as np

tau = 0.5
t_check = 1.0
y_exact = np.exp(-t_check / tau)
print("t=1 解析", y_exact)
```

**练习 ⭐**：改 `tau=0.2`，解析值变大还是变小？

## 3.2 显式欧拉法（必须手写一次）

\[
y_{k+1} = y_k + \Delta t \cdot f(y_k)
\]

对 \(\dot{y}=-y/\tau\)：

```python
tau, dt, y, t = 0.5, 0.05, 1.0, 0.0
for k in range(20):
    y = y + dt * (-y / tau)
    t += dt
print("Euler t=1 approx", y)  # 步数够时接近 exp(-2)
```

**要点**：\(\Delta t\) 太大 → 不稳定或明显失真；经验上 \(\Delta t \ll \tau\) 或小于系统最快模态周期的 1/20。

### 3.2.1 常见错误 vs 推荐

```python
# ❌ 用 f(y_{k+1}) 做显式欧拉（那是隐式，别混）
# y = y + dt * (-(y + dt*...)/tau)

# ❌ dt 与 tau 同量级还想 10 步走到稳态
# ✅ 先缩小 dt 或增加步数，再与解析解比
```

**练习 ⭐**：固定 `t_end=1`，比较 `dt=0.2, 0.05, 0.01` 与 `exp(-1/tau)` 的误差表。

## 3.3 二阶系统 → 一阶状态方程（标准套路）

弹簧–质量–阻尼：

\[
m \ddot{q} + b \dot{q} + k q = u
\]

令 \(x = [q,\ \dot{q}]^\top\)：

\[
\dot{x} = \begin{bmatrix} \dot{q} \\ (u - b\dot{q} - kq)/m \end{bmatrix}
\]

```python
def mass_spring_rhs(t, x, m=1.0, b=0.2, k=4.0, u=0.0):
    q, qd = x
    qdd = (u - b * qd - k * q) / m
    return [qd, qdd]
```

倒立摆是 **两个坐标、四个一阶状态**——完全同一套路，只是 \(f\) 更复杂。

**练习 ⭐**：纸笔推导：若只有重力恢复力 \(m\ddot{q}=-kq\)，`b=0,u=0` 时 `qdd` 是什么？

## 3.4 SciPy `solve_ivp`（推荐默认工具）

接口：**`f(t, x)` 返回 \(\dot{x}\)**（列表或 1d ndarray）。

```python
from scipy.integrate import solve_ivp
import numpy as np

def f(t, x):
    q, qd = x
    m, b, k = 1.0, 0.2, 4.0
    u = 0.0
    qdd = (u - b * qd - k * q) / m
    return [qd, qdd]

x0 = [0.1, 0.0]
sol = solve_ivp(f, (0.0, 5.0), x0, max_step=0.01, dense_output=True)
t = np.linspace(0, 5, 200)
x = sol.sol(t)   # shape (2, len(t))
q = x[0]
```

画图：

```python
import matplotlib.pyplot as plt
plt.plot(t, q)
plt.xlabel("t"); plt.ylabel("q"); plt.grid(True); plt.savefig("/tmp/msd.png")
```

**参数提示**：

- `max_step`：限制最大步长，避免漏掉快动态  
- `dense_output=True`：可在任意 `t` 上插值  
- `events`：可检测「\(|\theta|>30°\) 则停止」（选做）

### 3.4.1 `odeint` 与 `solve_ivp`

老教程常用 `scipy.integrate.odeint`；新代码优先 **`solve_ivp`**（接口更清晰、事件支持更好）。你若在知乎看到 `odeint` 片段，可对照改写：

```python

# solve_ivp：f(t, x) —— 与教材 \(\dot{x}=f(x,t)\) 更一致
```

## 3.5 固定步长仿真循环（与 MCU 思维一致）

嵌入式里常用 **固定 \(\Delta t\)**（如 1 ms）。Python 验证算法时可写：

```python
import numpy as np

def f(x, u, m=1.0, b=0.2, k=4.0):
    q, qd = x
    qdd = (u - b * qd - k * q) / m
    return np.array([qd, qdd])

dt = 0.001
x = np.array([0.1, 0.0])
u = 0.0
history = [x.copy()]
for k in range(5000):
    x = x + dt * f(x, u)
    history.append(x.copy())
hist = np.array(history)
```

内层用 **欧拉**；要精度可换 RK4（见 §3.6）。`src/inverted_pendulum/simulation.py` 后期走类似结构。

**常见错误 vs 推荐**

```python
# ❌ x = x + dt * f(x,u) 但 f 返回 list，与 ndarray 混用维度乱
# ✅ 统一 np.array，或全程 list

# ❌ 忘记存 history 只保留最后状态
```

## 3.6 RK4 四阶龙格–库塔（读仓库实现）

简化摆状态 \(x=[\theta,\omega]^\top\)，力矩 \(u\)：

\[
\dot\theta = \omega,\quad
\dot\omega = -\frac{g}{L}\sin\theta - b\omega + \frac{u}{mL^2}
\]

仓库 `src/ai01/pendulum.py` 提供 `pendulum_deriv` 与 `rk4_step`。你不需要第一周就推导 RK4 公式，但要会读：

```text
k1 = f(x)
k2 = f(x + dt/2 * k1)
...
x_next = x + dt/6 * (k1 + 2*k2 + 2*k3 + k4)
```

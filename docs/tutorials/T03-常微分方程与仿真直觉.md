## 学习目标

理解 \(\dot{x}=f(x,u)\)、离散时间 **欧拉 / RK4**、`scipy.integrate.solve_ivp`；能对比固定步长与变步长结果。

## 知识要点

| 块 | 要点 |
|----|------|
| ODE 与状态 | 标量/向量状态；力矩 \(u\) 作为输入 |
| 欧拉法 | \(x_{k+1}=x_k + dt\, f(x_k,u_k)\)；步长与稳定性直觉 |
| RK4 | 四阶固定步长；与 `rk4_step` 对照读 `src/ai01/pendulum.py`（**只读**，本学期不写 NN） |
| `solve_ivp` | 事件、密集输出；与自写循环对比同一时刻状态 |
| 仿真工程 | 固定 `dt` 与控制周期；记录 `t, x` 便于画图 |

## 3.1 状态、输入与 ODE

连续时间系统常写成：

\[
\dot{x}(t) = f(x(t), u(t))
\]

- **x**：状态向量（例如 cart-pole 的 \(x, \dot{x}, \theta, \dot{\theta}\)）  
- **u**：控制输入（例如施加在小车上的水平力）  
- **f**：由物理定律得到的动力学

**仿真**就是：给定初值 \(x(t_0)\) 和输入序列 \(u(t)\)，数值逼近 \(x(t)\) 在离散时间点上的值。

## 3.2 一阶标量：欧拉法（理解误差来源）

对 \(\dot{y} = -y/\tau\)（与 T02 一阶系统一致），显式欧拉：

\[
y_{k+1} = y_k + \Delta t \cdot \left(-\frac{y_k}{\tau}\right)
\]

```python
import numpy as np

tau = 0.5
dt = 0.05
y = 0.0
t = 0.0
for _ in range(60):
    y = y + dt * (-y / tau)
    t += dt
```

**要点**：\(\Delta t\) 太大 → 数值不稳定或明显失真；工程上常取 \(\Delta t\) 为时间常数的 1/10～1/100。

---

## 3.3 二阶系统 → 一阶状态方程

弹簧–质量–阻尼：\(m \ddot{q} + b \dot{q} + k q = u\)。

令状态 \(x = [q, \dot{q}]^\top\)：

\[
\dot{x} = \begin{bmatrix} \dot{q} \\ \ddot{q} \end{bmatrix}
= \begin{bmatrix} x_2 \\ (u - b x_2 - k x_1)/m \end{bmatrix}
\]

这与倒立摆「两个二阶坐标 → 四个一阶状态」是同一套路。

## 3.4 用 SciPy 解 ODE（推荐）

```python
from scipy.integrate import solve_ivp
import numpy as np

def f(t, x):
    q, qd = x
    m, b, k = 1.0, 0.2, 4.0
    u = 0.0  # 暂无力输入
    qdd = (u - b * qd - k * q) / m
    return [qd, qdd]

x0 = [0.1, 0.0]
sol = solve_ivp(f, (0.0, 5.0), x0, max_step=0.01, dense_output=True)
t = np.linspace(0, 5, 200)
x = sol.sol(t)
```

`solve_ivp` 自动变步长，比手写欧拉稳健；**必做**是理解 `f(t, x)` 的接口：`t` 当前时间，`x` 当前状态，返回 \(\dot{x}\)。

## 6.1 MDP 五元组（背概念即可）

把「和环境一轮一轮交互」写成：

\[
(\mathcal{S},\; \mathcal{A},\; P,\; R,\; \gamma)
\]

| 符号 | 含义 | 平衡车 / cart-pole 例子 |
|------|------|-------------------------|
| \(\mathcal{S}\) | 状态空间 | \(s=[\theta,\omega,p,\dot p]\) 或传感器读数 |
| \(\mathcal{A}\) | 动作空间 | 轮力矩、目标速度；离散推左/推右亦可 |
| \(P(s'|s,a)\) | 转移 | 仿真里就是 ODE / MJCF 积分一步 |
| \(R(s,a)\) | 奖励 | 例如 \(r=-\theta^2-0.01 a^2\)（直立 + 省力） |
| \(\gamma\in(0,1]\) | 折扣 | 更看重近期奖励 |

**策略** \(\pi(a|s)\)：看到状态就给出动作（查表或神经网络）。  
目标：最大化期望回报 \(\mathbb{E}\sum_t \gamma^t r_t\)。

### 6.1.1 和 T03 仿真循环差在哪

```text
T03/T04（你已经会）：
  每个 dt：读状态 → u = PID 或你写死的 u(t) → 积分 f(x,u)

RL（阶段四才做）：
  每个 dt：读 s → a ~ π(s) → 环境步进 → 得到 r 与 s'
  用许多回合的 (s,a,r,s') 更新 π，使回报变大
```

**练习（选做）**：用自己的话写 4 行：\(s,a,r,\pi\) 在两轮车上各是什么。不要写训练代码。

## 6.2 与 LQR、PID、T05 对照（复试话术）

| | PID（T04） | LQR（寒假主线） | 一步 MLP（T05） | RL（如 PPO） |
|--|-----------|----------------|-----------------|--------------|
| 要什么 | 误差 \(e=r-y\) | 线性模型 \(A,B\) + \(Q,R\) | 有标签的 \(x^+\) | 奖励 \(R\)，可无解析模型 |
| 产出 | 标量控制律 | \(u=-Kx\) | 开环预测器 | 闭环策略 \(\pi\) |
| 调参 | \(K_p,K_i,K_d\) | \(Q,R\) 有物理意义 | `hidden_dim` / lr | 奖励塑形、很大经验 |
| 保证 | 经验整定 | 线性二次下最优 | 验证 MSE | 稳定性需另证 |
| 工程 | 实物常用 | 实物常用 | 辨识 / 残差模型 | 仿真多，sim-to-real 难 |

**一分钟叙事建议**：先讲「我用 ODE + PID/LQR 能站住」，再讲「我用数据拟合过一步动力学」，最后才说「RL 是备选，用来对比可解释性」。

## 6.3 MuJoCo 在本项目中的位置

寒假阶段在 [`sim/mujoco/`](../../sim/mujoco/) 放置 MJCF 与 Python 驱动脚本：

1. 安装 Python 绑定，跑通官方 demo（固定随机种子）。  
2. 改编 **两轮平衡车 MJCF**（车体、轮、关节、IMU 类传感器）。  
3. 从模型或解析式导出线性化 \(A,B\)，与阶段一公式对照。  
4. 先 **LQR** 站稳，再（可选）上 RL 做对比。

安装与版本**不**写入当前 `requirements.txt`；见 [`docs/ROADMAP.md`](../ROADMAP.md) 阶段二 **M2.1–M2.4**。

## 6.5 常见误区

| 误区 | 纠正 |
|------|------|
| 「Week 1 先把 RL 跑通更高级」 | 没有模型语言，面试会被追问到 ODE / 线性化就停 |
| 「T05 已经是强化学习」 | T05 有真值标签，是监督式系统 ID |
| 「上了 MuJoCo 就必须 PPO」 | 官方与开源平衡车大量是 LQR/PID |
| 「奖励写成 \(-\theta^2\) 就够了」 | 往往还要惩罚角速度、力矩、位移；塑形本身是门课 |

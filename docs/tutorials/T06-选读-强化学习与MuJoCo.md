## 6.1 MDP 五元组（背概念即可）

\((\mathcal{S}, \mathcal{A}, P, R, \gamma)\)

- **状态** \(s\)：仿真里常为关节角、角速度、车体速度  
- **动作** \(a\)：轮电机力矩或目标速度  
- **奖励** \(r\)：例如 \(r = -\theta^2 - 0.01 a^2\)（直立 + 省力）  
- **策略** \(\pi(a|s)\)：神经网络或查表

目标：最大化 \(\sum \gamma^t r_t\)。

---

## 6.2 与 LQR 的对比（复试话术）

| | LQR | RL（如 PPO） |
|---|-----|----------------|
| 模型 | 需要线性化 \(A,B\) | 可与环境交互，模型可黑盒 |
| 调参 | \(Q,R\) 有物理意义 | 奖励塑形需要经验 |
| 保证 | 线性二次下最优 | 收敛与稳定性需额外论证 |
| 工程 | 实物常用 | 仿真研究多，sim-to-real 难 |

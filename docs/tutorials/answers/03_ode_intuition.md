# 03 ODE · 参考思路

## 必做 1（力矩切换）

约在 \(t = steps/2 \cdot dt = 100 \times 0.02 = 2\) s 处，`u` 从 `u_pos` 变为 `u_neg`；\(\theta\) 由持续增大转为开始回落或振荡减弱（取决于阻尼），\(\omega\) 在切换点附近斜率改变。

## 必做 2（阻尼项）

`omega_dot` 中的 **`- p.b * omega`**。

## 必做 3（单步 rk4）

在 `PYTHONPATH` 含 `src` 时，典型输出形状 `(2,)`，\(\theta\) 略增、\(\omega\) 为负小量（重力使摆向下加速）。精确数值依赖 `PendulumParams` 默认；可用 `print(next_state)` 记录到笔记。

## 选做 2（采样范围）

\([-0.8, 0.8]\) rad 已含明显非线性又避免贴近 \(\pm\pi\) 不稳定区；且与「一步预测」任务难度、MCU 将来小角度工作点一致。

# 05 控制预备 · 参考思路（T04）

## 自测（T04 §4.15）

1. 教材默认 \(e=r-y\)。写成 \(y-r\) 会变成正反馈，容易发散。  
2. 纯 P 相当于有限增益；一阶对象常常到不了 \(r\)（余差）。  
3. `integral` 带着上一条轨迹；换初值或改增益前必须 `reset()`。  
4. \(A\)：无输入时状态自己怎么演化；\(B\)：输入如何进入 \(\dot x\)。  
5. 直立 \(\theta=0\) 是工作点；小角度 \(\sin\theta\approx\theta\)，线性 \(A,B\) 才有意义。

## 手算 PID（§4.4.2）

`Kp=2, Ki=0, Kd=1`, `dt=0.1`：先 `step(0.2)`（此时 `prev_error=0`），再 `step(0.1)`。  
第二拍：`d_error=(0.1-0.2)/0.1=-1`，`u=2*0.1+0+1*(-1)=-0.8`。  
实现限幅时必须对 **`u_raw`** 做 `max/min`，不要对尚未赋值的 `u`。

## 质量–弹簧 P 控制

`u=-Kp*q`（或 PID 的 `e=0-q`）应把 `q` 往 0 拉。`Kp` 过大开始振荡——记下曲线，不要只报一个末值。

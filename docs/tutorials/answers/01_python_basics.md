## 自测（T01 §1.20）

1. `range(1, 6)` → `1,2,3,4,5`（不含 6）。  
2. `clamp(15, -10, 10)` → `10.0`；电机指令不能超过驱动器范围。  
3. `list` 适合有序采样序列；`dict` 适合 `m, L, g` 这类命名参数。  
4. 二进制浮点无法精确表示 `0.1`；用容差 `abs(a-b) < 1e-9`。  
5. 被 `import` 时不自动跑仿真；直接 `python 文件.py` 才进 `main()`。  
6. `__init__` 在构造对象时调用；`self` 是「这个实例」。  
7. 每步 `PID(...)` 会把 `integral` 清零，积分项永远累加不上。

## 一阶阶跃预习（§1.4）

`tau = 0.5` 时 \(y(1)=1-e^{-2}\approx 0.8647\)。  
若误写成 `2**(-1/tau)` 会得到 `0.75`——那是以 2 为底，不是 \(e^{-t/\tau}\)。

## 综合第 2 组：`euler_decay`

`y ← y + dt*(-y/tau)`，`y0=1`, `tau=0.5`, `dt=0.05`，20 步后应接近 \(e^{-1}\approx 0.368\)（欧拉会略偏）。

## T01b 闭环 50 步

- `PID` 在 `for` **外**创建；调参前 `reset()`。  
- `FirstOrderPlant`：`dy = (setpoint - y)/tau + ku*u`。`ku=0` 时 `u` 进不了对象，闭环与开环无区别。  
- `Ki=0` 时稳态 `y` 往往 **低于** `r`（纯 P 有余差）；加一点 `Ki` 可拉回。骨架见 T01b §B.4。

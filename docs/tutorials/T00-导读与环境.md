## 0.1 你在学什么、为什么从倒立摆开始

两轮自平衡小车在复试里是一个**好讲故事**的系统：有物理模型、有经典 PID/LQR、有仿真与实物对比，还可以加一段「学习控制 vs 经典控制」（**寒假以后**再展开，见 [T06](T06-选读-强化学习与MuJoCo.md)）。

数学上，**小车上的摆杆**在小角度、轮轴近似为支点时，与 **cart-pole（小车–倒立摆）** 共享同一类状态方程。因此本仓库**大三上**先练倒立摆 Python 仿真，**寒假**再上 MuJoCo 两轮车，**大三下**做 MCU 实物。

你现在不需要会推导拉格朗日方程；只需要记住三条（后面每周都会重复）：

1. **状态** \(x\)：系统在某一时刻的「全貌」（位置、角度、速度等）。  
2. **控制输入** \(u\)：电机力矩或力。  
3. **仿真**：在计算机里按时间步推进 \(x\)，看闭环是否稳定。

### 0.1.1 先跑通：30 秒感受「状态在变」

环境装好以后（见 §0.3），在项目根目录执行：

```bash
python - <<'PY'
# 极简「仿真」：不用库，只看状态怎么一步步变
x, v = 0.0, 1.0   # 位置、速度
dt = 0.1
for k in range(5):
    x = x + dt * v      # 匀速模型：位置 += 速度 * dt
    print(f"k={k}  x={x:.2f}  v={v:.2f}")
PY
```

这不是倒立摆，而是让你习惯：**循环 + 更新变量 = 离散时间仿真**。T03 会把 `x` 换成向量，用 SciPy / RK4。

**本节练习**

1. 把 `v` 改成 `2.0`，预测 `k=4` 时 `x` 是多少，再运行核对。  
2. 在笔记里写一句：平衡车 IMU 读的「角速度」对应状态里的哪一类量？

## 0.3 开发环境：VS Code + WSL + Python

### 0.3.1 WSL 与路径

- 建议把项目放在 WSL 文件系统内，例如 `~/projects/balance-bot`，避免 `/mnt/c/...` 上 IO 过慢。  
- VS Code 使用 **Remote - WSL** 扩展打开文件夹。

**常见错误 vs 推荐**

| ❌ 容易踩坑 | ✅ 推荐 |
|------------|--------|
| 在 `/mnt/c/Users/...` 下 `pip install` 很慢 | 克隆到 `~/projects/...` |
| 用系统 Python 全局装包 | 每项目一个 venv / conda 环境 |
| 在 `weeks/week01/` 里 `python ex01_syntax.py` 导致相对路径错乱 | **始终在项目根**执行 `python weeks/week01/ex01_syntax.py` |

### 0.3.2 Python 版本

需要 **Python 3.10+**：

```bash
python3 --version
```

### 0.3.3 虚拟环境（推荐 venv）——按顺序跑通

在**项目根目录**：

```bash
python3 -m venv .venv
source .venv/bin/activate   # Windows WSL 同上；PowerShell 用 .venv\Scripts\Activate.ps1
pip install -U pip
pip install -r requirements.txt
```

**验证单元 1：核心科学栈**

```bash
python -c "import numpy, scipy, matplotlib; print('OK', numpy.__version__)"
```

**验证单元 2：能否画图（无显示器会走 Agg，见 hello_sim）**

```bash
python weeks/week01/hello_sim.py
```

应看到终端说明或生成 `weeks/week01/week01_step_response.png`。

### 0.3.4 使用 conda（可选）

若你更习惯 **conda**（例如环境名 `pendulum`）：

```bash
conda create -n pendulum python=3.11 -y
conda activate pendulum
cd /path/to/repo
pip install -r requirements.txt
```

原则与 venv 相同：**每个项目独立环境**，不要全局 `pip install` 污染。

### 0.3.5 后续导入 `inverted_pendulum` / `ai01`

在根目录：

```bash
export PYTHONPATH="${PYTHONPATH}:$(pwd)/src"
python -c "from ai01.pendulum import pendulum_deriv; print('ai01 OK')"
```

或在 VS Code 里把 `src` 标记为源码根目录。未设置 `PYTHONPATH` 时，`weeks/ai01/` 脚本会 import 失败——这是**预期错误**，用来提醒你配置路径。

## 0.1 你在学什么、为什么从倒立摆开始

两轮自平衡小车在复试里是一个**好讲故事**的系统：有物理模型、有经典 PID/LQR、有仿真与实物对比，还可以加一段「学习控制 vs 经典控制」。

数学上，**小车上的摆杆**在小角度、轮轴近似为支点时，与 **cart-pole（小车–倒立摆）** 共享同一类状态方程。因此本仓库**大三上**先练倒立摆 Python 仿真，**寒假**再上 MuJoCo 两轮车，**大三下**做 MCU 实物。

你现在不需要会推导拉格朗日方程；只需要记住三条：

1. **状态**描述系统在某一时刻的「全貌」（位置、角度、速度等）。  
2. **控制输入**是电机力矩或力。  
3. **仿真**就是在计算机里按时间步推进状态，看闭环是否稳定。

## 0.3 开发环境：VS Code + WSL + Python

### 0.3.1 WSL 与路径

- 建议把项目放在 WSL 文件系统内，例如 `~/projects/balance-bot`，避免 `/mnt/c/...` 上 IO 过慢。  
- VS Code 使用 **Remote - WSL** 扩展打开文件夹。

### 0.3.2 Python 版本

需要 **Python 3.10+**：

```bash
python3 --version
```

### 0.3.3 虚拟环境（推荐 venv）

在**项目根目录**：

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -U pip
pip install -r requirements.txt
python -c "import numpy, scipy, matplotlib; print('OK')"
```

### 0.3.4 使用 conda（可选）

若你更习惯 **conda**（例如环境名 `pendulum`）：

```bash
conda create -n pendulum python=3.11 -y
conda activate pendulum
cd /path/to/repo
pip install -r requirements.txt
```

原则与 venv 相同：**每个项目独立环境**，不要全局 `pip install` 污染。

### 0.3.5 后续导入 `inverted_pendulum`

在根目录：

```bash
export PYTHONPATH="${PYTHONPATH}:$(pwd)/src"
```

或在 VS Code 里把 `src` 标记为源码根目录。

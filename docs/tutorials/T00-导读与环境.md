## 环境：VS Code + WSL + Python 3.10+

| 步骤 | 说明 |
|------|------|
| 路径 | 项目放在 WSL 内 `~/projects/...`，避免 `/mnt/c` 慢 IO |
| venv | 根目录：`python3 -m venv .venv` → `source .venv/bin/activate` → `pip install -r requirements.txt` |
| conda（可选） | `conda create -n pendulum python=3.11` 后同样 `pip install -r requirements.txt` |
| 验证 | `import numpy`；`python weeks/week01/examples/hello_sim.py`（无显示器会保存 PNG 到同目录） |
| `src` 包 | 读 `inverted_pendulum` / 寒假 `ai01` 时：`export PYTHONPATH="$(pwd)/src"` |

**常见坑**：在子目录里 `python ex01.py` 导致路径乱 → **始终在根目录**带 `weeks/...` 前缀。

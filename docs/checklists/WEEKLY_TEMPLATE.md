# 周学习清单 · 模板

> 复制本文件为 `docs/checklists/YYYY-Www.md`（ISO 周次），填好日期与「本周项目/教程」链接即可。  
> **周日 20:30** 用当周文件做复盘（见文末）。

**课表**：先列出当周**上课占用时段**，再把自习块**填在空档**里。机器人/自动化类学期常见节奏：**周三无课 + 周六日** 默认作为 **数学 + 自控 + 项目/教程** 的深度日；**周一、二、四、五** 课多日用短块保 **每日单词** 与跟课复习。

**CET-6**：**单词** 每天 20–30 min（写在下方每日打卡，不攒周末）。**听力** 不在每日行里堆——在「听力固定槽」里 **每周预定 2–3 次**（每次约 30–45 min，精听 + 对答案）。可参考 [`2026-W42.md`](2026-W42.md)。

## 每日建议时长（工作日默认）

| 模块 | 目标 | 备注 |
|------|------|------|
| **数学（张宇）** | 60–90 min | 刷题 + 错题 |
| **自控** | 40–60 min | 跟课/教材 + 小练习 |
| **项目 / 教程** | 60–90 min | 见 [`docs/tutorials/README.md`](../tutorials/README.md) 与当周条目 |
| **CET-6 · 单词** | **每天** 20–30 min | **不可只堆周末**；课多日也要保单词块 |
| **CET-6 · 听力** | **每周 2–3 次** | 只写在下方「听力固定槽」，**不与单词混在同一行** |
| **「自己写」作业** | 穿插在项目日 | 不抄完整答案，留可运行片段 |
| **专业课（可选）** | 跟课即可 | C / C++ / MATLAB 实验与作业 |

**兜底日**：若某天只能「保底」，仍要 **CET-6 单词 20 min**；并优先 **数学 30–45 min + 自控 20–30 min**。项目/教程可挪到相邻日或周末补块（**单词不挪**；**听力槽**可挪到相邻空档，但本周仍要完成 **2–3 次**）。

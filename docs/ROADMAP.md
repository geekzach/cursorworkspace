# 两轮自平衡小车 — 学习路线图

面向 **东南大学 085400 电子信息（专硕）** 复试准备，方向倾向 **具身智能 / 嵌入式控制**。本项目以 **「先仿真、后实物」** 为主线：用倒立摆打好数学与经典控制基础，再在 MuJoCo 中搭建两轮自平衡小车，最后落地 MCU 实物，并可选做强化学习实验与复试答辩材料串联。

> **当前进度（2026 年 10 月）**：仅完成 **Week 1**（`weeks/week01/`）— Python 基础与环境搭建。  
> MuJoCo、LQR 闭环、实物硬件、强化学习等 **均未实现**；`src/inverted_pendulum/` 仍为包骨架。

---

## 设计原则

1. **先仿真、后硬件**：在主机上验证模型与控制律，再移植到 MCU，降低炸机/烧驱动风险。
2. **分层架构**：MCU 负责 **实时电机控制**（目标周期 **&lt; 1 ms** 量级）；主机负责仿真、参数整定、高层规划或学习实验。
3. **从成熟开源起步**：倒立摆 / 平衡车均有大量教材与开源实现，先读懂再改，避免从零造轮子。
4. **复试可讲**：每一阶段留下 **图、公式、代码片段、对比曲线**，便于整理进 PPT。

## 阶段一：大三上（2026.10 — 2027.01）— 倒立摆基础

**主题**：Python 入门、拉格朗日建模、线性化、PID。

| 里程碑 | 内容 | 产出物（建议） |
|--------|------|----------------|
| M1.1 | 完成 Week 1–2：语法、函数、numpy、简单 ODE | 可运行的练习脚本、`CHECKLIST` 打勾 |
| M1.2 | 一维/二维倒立摆（cart-pole）**运动学与动力学**：拉格朗日方程 → 状态方程 | 手写推导笔记 + `model.py` 中公式与代码对应 |
| M1.3 | 工作点线性化、开环仿真 | 状态曲线图（角度、角速度等） |
| M1.4 | PID（或 PD）在简化模型上整定 | 阶跃/扰动响应对比图 |
| M1.5 | 能口头说明：**倒立摆 ≈ 平衡车在「轮轴为支点」的等效模型** | 复试用「从摆到车」一页示意图 |
| **M1.6**（**AI 支线，可选**） | **轻量 NN 动力学拟合**：用简化摆 ODE 生成 rollout，训练小型 MLP 预测下一状态；对比真值与预测误差 | `weeks/ai01_nn_dynamics/`、`src/learning/`；面试可讲「经典模型 + 数据驱动近似」 |

**与本仓库**：继续按周次填充 `weeks/week0x/` 与 `src/inverted_pendulum/`（`model.py`、`controllers/pid.py`、`simulation.py` 等）。**不要求**本阶段引入 MuJoCo。  
**AI 支线**与 Week 1–2 **并行**：不替代拉格朗日推导与 PID；完成后更易理解阶段四 **M4** 中「仿真环境 + 学习」的关系（本阶段 **不做 RL**）。

**依赖**：`requirements.txt` 中的 numpy / scipy / matplotlib；后续周次可增加 `python-control`（见 README）。

## 阶段二：寒假（2027.01 — 2027.02）— MuJoCo 仿真

**主题**：MJCF 建模两轮自平衡小车、LQR 平衡控制。

| 里程碑 | 内容 | 产出物（建议） |
|--------|------|----------------|
| M2.1 | 安装 MuJoCo（Python 绑定），跑通官方或开源 demo | 环境截图、固定随机种子可复现 |
| M2.2 | 编写/改编 **两轮平衡车 MJCF**（车体、轮、关节、传感器：IMU 位姿/角速度等） | `sim/mujoco/` 下模型文件与说明 |
| M2.3 | 从 MJCF 或解析模型导出 **线性化状态空间**（与阶段一公式对照） | 文档中 A、B 矩阵与物理意义 |
| M2.4 | **LQR** 设计全状态反馈（或简化输出反馈），仿真稳定站立 | 平衡时长、最大倾角、控制量曲线 |
| M2.5 | 参数敏感性：质量、轮距、延迟等扫掠 | 1–2 张对比图写入笔记 |

**与本仓库**：代码计划放在 [`sim/mujoco/`](../sim/mujoco/)（当前为占位目录）。**暂不**将 `mujoco` 写入根目录 `requirements.txt`；寒假开始时单独记录版本与安装步骤。

## 阶段三：大三下（2027.03 — 2027.06）— 实物硬件

**主题**：ESP32 或 STM32（**C 语言**）、IMU + 编码器电机，PID/LQR 移植，仿真与实物对比。

| 里程碑 | 内容 | 产出物（建议） |
|--------|------|----------------|
| M3.1 | 硬件选型与采购、机械组装（两轮 + 摆杆或一体车体） | 实物照片、接线图 |
| M3.2 | IMU 姿态解算、编码器测速，**固定周期**控制循环（如 500 Hz–1 kHz） | 串口/日志波形 |
| M3.3 | 先 **PID** 站稳，再尝试 **LQR**（或增益调度） | 站立视频、倾角曲线 |
| M3.4 | 与 MuJoCo **同参数**或同结构对比：稳态误差、抖动、饱和 | 复试用「仿真 vs 实物」一页 |
| M3.5 | 安全与故障：倾角过大断电、看门狗、限幅 | 简短安全说明 |

**语言分工**：主机 Python（仿真、调参、日志分析）；MCU **C**（实时控制）。避免在 MCU 上跑重型 Python。

**主题**：在 MuJoCo 中做 **简单强化学习** 平衡实验（策略网络 + 奖励设计），与经典 LQR 对比。

| 里程碑 | 内容 | 产出物（建议） |
|--------|------|----------------|
| M4.1 | 定义状态、动作、奖励（倾角、角速度、力矩惩罚等） | 奖励函数公式与 ablation 笔记；可回顾阶段一 **M1.6** 的「一步动力学拟合」与闭环 RL 的差异 |
| M4.2 | 训练简单策略（如 PPO / 小型 MLP），能短时平衡 | 训练曲线、策略 rollout 视频 |
| M4.3 | 与 LQR 对比：鲁棒性、调参成本、可解释性 | 复试「经典 vs 学习」讨论要点 |
| M4.4 | 可选：Sim-to-real 讨论（不强制上实物 RL） | 文献 1–2 篇读后感 |

此阶段为 **面试加分项**，不影响「经典控制主线」的完整性。

## 复试 PPT 建议叙事线（2028 年初）

按时间或按技术栈组织均可，推荐 **六段式**（与上述阶段对应）：

| 章节 | 建议内容 | 时长参考 |
|------|----------|----------|
| 1. 建模 | 从 cart-pole 拉格朗日 → 两轮车简化模型；状态变量定义 | 2–3 min |
| 2. 经典控制 | PID 整定思路、抗饱和、实物噪声 | 2 min |
| 3. 现代控制 | 线性化、可控可观、LQR 代价函数与 Q/R 选取 | 2–3 min |
| 4. 仿真 | MuJoCo 场景、传感器、与理论模型一致性 | 1–2 min |
| 5. 实物 | 硬件框图、实时循环、仿真–实物对比曲线/视频 | 2–3 min |
| 6. 学习控制 | RL 实验动机、结果、与 LQR 对比；具身智能展望 | 1–2 min |

**答辩准备**：每章准备 1 个「面试官可能追问」— 例如：为什么倒立摆能代表平衡车？LQR 失效时怎么办？MCU 控制周期多少、如何测？

## 硬件 BOM（ tentative / 暂定，仅供参考）

> 未标注价格；采购前请对照开源平衡车项目（如国内 DIY 平衡小车、ESP32-Balance 等）核对型号与兼容性。**非本仓库 Week 1 必需。**

| 类别 | 建议器件 | 备注 |
|------|----------|------|
| 主控 | ESP32（双核、Wi-Fi 便于调参）或 STM32F4 系列 | 需足够 ADC/GPIO/PWM 定时器 |
| IMU | 6 轴 MEMS（如 MPU6050 / ICM-42688 等） | 注意 I2C/SPI 速率与滤波 |
| 驱动 | 双路直流电机驱动（带电流采样更佳） | 与电机电压、电流匹配 |
| 电机 | 带编码器的直流减速电机 ×2 | 编码器分辨率影响速度环 |
| 电源 | 锂电池 + BMS、稳压模块 | 注意电机与逻辑电分离/共地 |
| 机械 | 两轮车体套件或 3D 打印车架、轮系 | 轮距、重心高度影响平衡难度 |
| 调试 | USB 串口、逻辑分析仪（可选） | 用于验证控制周期与中断 |
| 安全 | 急停开关、保险丝、海绵限位 | 首次上电必备 |

# 复试与项目

> 报考规则见 [`SEU_备忘.md`](SEU_备忘.md)；本学期的项目周任务见 [`SEMESTER_PLAN.md`](SEMESTER_PLAN.md)。

## 复试概况（以 2025 年自动化学院细则为例）

- 笔试：5c5 自动控制原理（现代），闭卷 150 分钟，满分 150，90 分以下不进面试
- 笔试范围：田玉平第 3 章、4.6、第 7 章
- 面试：外语听说 + 专业 / 工程实践
- 综合成绩：初试 62.5% + 复试 37.5%，学硕和专硕分开排名

## 现代控制第一遍：大三下（2027.3–5），跟着项目学

目标是真正理解，不用刷题。初试后只有大约 10 周，中间还有期末和春节，所以第一遍必须在大三下完成。

- [ ] DR_CAN 状态空间相关系列（建立直觉）
- [ ] 田玉平第 3 章 状态空间模型：状态方程、与传递函数互化、状态转移矩阵、离散状态空间
- [ ] 田玉平 4.6 李雅普诺夫稳定性分析
- [ ] 田玉平第 7 章：能控能观、结构分解、规范型、状态反馈与输出反馈、极点配置、观测器
- [ ] 每部分做一些课后题
- [ ] 如果西电大三下有现代控制理论课，认真上

2027 年 7–12 月不碰现代控制，全力准备初试。

## 初试后集中突击（约 10 周）

不要等 2 月出成绩再开始。

- [ ] 第 1 周：休息两三天，对答案估分
- [ ] 第 2–5 周：精读田玉平第 3 章、4.6、第 7 章，课后题全做，每天 4–5 小时
- [ ] 第 6–8 周：刷题，按 150 分钟限时模拟
  - [ ] 往年 5c5 回忆题（如果能找到）
  - [ ] 刘豹《现代控制理论》习题
  - [ ] 其他学校的现代控制真题
- [ ] 第 9–10 周：继续模拟，同时准备面试（见最后的清单）
- [ ] 出分后给意向导师发邮件

## 项目：两轮自平衡车（PID 对比 LQR）

作用：第一遍学现代控制 + 面试里的工程实践 + 对口无锡智能机器人方向。

- 仿真代码在 [`code/inverted_pendulum/`](../code/inverted_pendulum/)（`model` / `simulation` / `controllers` / `plotting`）
- 学期中每周 5–6 小时，只放在周三晚上和周六下午
- 初试前不做 MuJoCo、强化学习、神经网络拟合

### 全程时间线

- [ ] 2026.10–12（仿真）：ODE 数值积分 → 推小车-倒立摆模型 → 线性化得 A、B → 离散 PID 闭环曲线（周任务见 SEMESTER_PLAN）
- [ ] 2027.1：期末，暂停；硬件下单
- [ ] 寒假（春节后集中两周，每天约 2 小时）：
  - [ ] IMU 读数，互补滤波得到倾角
  - [ ] 编码器测轮速
  - [ ] 电机驱动调通
  - [ ] 直立环 PID 站稳，再加速度环
- [ ] 2027.3–4：
  - [ ] 推导两轮平衡车模型（车轮 + 车身，拉格朗日方法）
  - [ ] 判断能控性，做极点配置和 LQR，先在 `controllers/lqr.py` 里仿真再上实物
  - [ ] 加观测器或卡尔曼滤波
  - [ ] 选采样周期，把控制器离散化（同时练了 835 的离散部分和 5c5 的离散状态空间）
  - [ ] PID 和 LQR 对比实验，记录数据
- [ ] 2027.5：整理报告、演示视频、代码仓库、PPT
- [ ] 2027.6：冻结，不再投入大块时间
- [ ] 初试后：重新熟悉项目，打磨讲解

### 硬件（预算几百元）

- [ ] ESP32 或 STM32 主控
- [ ] 带编码器的直流减速电机 ×2，加电机驱动（如 TB6612）
- [ ] IMU（如 MPU6050）
- [ ] 电池、车架

### 报告里必须有（复试笔试和面试都会问）

每一项都自己推导，不要只调用现成的库。

- [ ] 非线性模型和线性化推导
- [ ] 状态空间模型和能控性判断
- [ ] 极点配置的设计过程（第 7 章核心）
- [ ] LQR 的设计过程，Q、R 的选择理由
- [ ] 观测器或卡尔曼滤波的设计
- [ ] 采样周期的选择和离散化方法
- [ ] PID 和 LQR 的对比数据和曲线（超调、调节时间、抗扰动）
- [ ] 仿真结果和实物结果对比

### 有余力再做

- [ ] MPC
- [ ] 挂靠大创项目，或申请软件著作权（不要占用暑假）

## 面试准备清单（初试后）

- [ ] 英文自我介绍（1–2 分钟）
- [ ] 英文常见问答：学校、专业、研究兴趣、为什么选东南
- [ ] 项目讲解：3 分钟版和 10 分钟版，配 PPT，按"要解决什么问题、用了什么方法、结果怎样、有什么不足"四段讲
- [ ] 专业问答：经典控制和现代控制的核心概念
- [ ] 联系导师：出分后发邮件，附简历和项目材料；报专硕的话，重点看无锡智能机器人方向的导师

## 环境（Windows + conda，主）

系统自带的 Python 3.14 装不上 `requirements.txt` 里固定的 numpy / scipy / matplotlib 版本，要单独建一个 Python 3.12 环境。

1. 没有 conda 的话，先装 [Miniconda](https://docs.anaconda.com/miniconda/)（Windows 64 位安装包），装完在 PowerShell 里执行一次 `conda init powershell`，然后重开终端。
2. 在 **PowerShell**（仓库根目录）：

```powershell
conda create -n inverted-pendulum python=3.12 -y
conda activate inverted-pendulum
pip install -U pip
pip install -r requirements.txt
$env:PYTHONPATH = "$PWD\code"
python code/week01/exercises/ex01_syntax.py
python code/week01/examples/hello_sim.py
```

读 `code/inverted_pendulum` 时每次开终端可再设：`$env:PYTHONPATH = "$PWD\code"`（或写入 VS Code 终端配置）。

## 环境（Linux / macOS · venv）

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -U pip && pip install -r requirements.txt
export PYTHONPATH="${PYTHONPATH}:$(pwd)/code"
python code/week01/exercises/ex01_syntax.py
```

## WSL 备注

本机常用 **Windows + conda**，代码也可放在 WSL 里用 venv；`PYTHONPATH` 用 Linux 路径 `$(pwd)/code`。Matplotlib 中文标签见 `code/inverted_pendulum/plotting.py` 的 `configure_matplotlib_chinese()`。

**验收**：`import numpy, scipy, matplotlib` 成功；跑通 `ex01_syntax` 与 `hello_sim`。

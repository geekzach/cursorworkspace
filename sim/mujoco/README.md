# MuJoCo 仿真（寒假阶段占位）

本目录计划在 **2027 年寒假（阶段二）** 使用，用于：

- 两轮自平衡小车的 **MJCF** 模型（车体、双轮、关节、IMU 等传感器）；
- 在仿真中实现 **LQR**（及后续可选 **强化学习**）平衡控制；
- 与 `src/inverted_pendulum/` 中的解析模型、线性化结果做对照。

**当前状态**：仅占位，**无任何仿真代码**。根目录 `requirements.txt` **尚未**加入 `mujoco`；寒假开始安装时再记录版本与步骤（见 [`docs/ROADMAP.md`](../../docs/ROADMAP.md)）。

建议起步方式：

1. 安装 MuJoCo Python 包并跑通官方示例；
2. 从成熟开源平衡车 MJCF 改编，避免从零写碰撞与关节；
3. 固定随机种子，保存「能站稳」的一组 Q/R 与物理参数，便于写进复试笔记。
